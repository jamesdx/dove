# 微服务架构规划任务执行指南

你是一位资深的DDD架构师。请按照以下步骤执行微服务架构规划并生成相应文档。

## 输入材料
1. 领域划分文档
2. 限界上下文定义
3. 统一语言词汇表

## 执行步骤

### 步骤1: 微服务边界划分
执行顺序:
1.1 边界分析
   - [ ] 评估限界上下文粒度
   - [ ] 分析业务自治程度
   - [ ] 评估数据内聚性

1.2 服务识别
   - [ ] 确定服务候选项
   - [ ] 评估服务独立性
   - [ ] 验证服务完整性

1.3 边界确认
   - [ ] 确定最终边界
   - [ ] 定义服务职责
   - [ ] 明确服务范围

### 步骤2: 服务间通信模式设计
执行顺序:
2.1 通信方式选择
   - [ ] 分析同步需求
   - [ ] 评估异步场景
   - [ ] 确定通信协议

2.2 事件设计
   - [ ] 识别领域事件
   - [ ] 设计事件结构
   - [ ] 规划事件流

2.3 接口设计
   - [ ] 定义服务接口
   - [ ] 设计数据格式
   - [ ] 规划版本策略

### 步骤3: 确定集成策略
执行顺序:
3.1 集成模式选择
   - [ ] 评估集成需求
   - [ ] 选择集成方式
   - [ ] 设计集成流程

3.2 一致性策略
   - [ ] 分析一致性要求
   - [ ] 选择一致性模式
   - [ ] 设计补偿机制

3.3 故障处理
   - [ ] 设计重试策略
   - [ ] 规划降级方案
   - [ ] 定义超时策略

### 步骤4: 设计防腐层
执行顺序:
4.1 需求分析
   - [ ] 识别外部依赖
   - [ ] 分析变更风险
   - [ ] 评估隔离需求

4.2 转换设计
   - [ ] 设计数据转换
   - [ ] 规划接口适配
   - [ ] 定义协议转换

4.3 实现策略
   - [ ] 选择实现方式
   - [ ] 设计错误处理
   - [ ] 规划版本兼容
