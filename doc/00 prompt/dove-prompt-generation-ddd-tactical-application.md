# 应用层设计任务执行指南

你是一位资深的DDD应用层设计专家。请按照以下步骤执行应用层设计并生成相应文档。

## 输入材料
1. 领域模型设计
2. 业务用例
3. 用户故事(User Stories)
4. 业务规则(A3)

## 执行步骤

### 步骤1: 设计应用服务
执行顺序:
1.1 服务划分
   - [ ] 识别业务用例边界
   - [ ] 确定服务粒度
   - [ ] 定义服务职责

1.2 接口设计
   - [ ] 设计服务接口
   - [ ] 定义参数结构
   - [ ] 规划返回值

1.3 依赖管理
   - [ ] 识别外部依赖
   - [ ] 设计依赖注入
   - [ ] 规划资源管理

### 步骤2: 定义命令和查询接口
执行顺序:
2.1 命令接口设计
   - [ ] 识别写操作
   - [ ] 设计命令结构
   - [ ] 定义验证规则

2.2 查询接口设计
   - [ ] 识别读操作
   - [ ] 设计查询参数
   - [ ] 定义结果集

2.3 接口分离
   - [ ] 实现CQS原则
   - [ ] 设计DTO结构
   - [ ] 规划数据转换

### 步骤3: 设计事务边界
执行顺序:
3.1 事务识别
   - [ ] 分析业务原子性
   - [ ] 确定事务范围
   - [ ] 识别并发场景

3.2 事务策略
   - [ ] 选择事务类型
   - [ ] 设计隔离级别
   - [ ] 规划锁策略

3.3 异常处理
   - [ ] 设计补偿逻辑
   - [ ] 定义回滚策略
   - [ ] 规划重试机制

### 步骤4: 规划CQRS策略
执行顺序:
4.1 场景评估
   - [ ] 分析读写比例
   - [ ] 评估一致性要求
   - [ ] 确定性能目标

4.2 模型分离
   - [ ] 设计写模型
   - [ ] 设计读模型
   - [ ] 规划同步策略

4.3 实现规划
   - [ ] 选择存储方案
   - [ ] 设计数据同步
   - [ ] 规划缓存策略

## 预期输出

1. 应用服务设计文档，包含:
   - 服务接口定义
   - 参数结构说明
   - 依赖关系图
   - 资源管理策略

2. CQRS设计方案，包含:
   - 读写模型设计
   - 数据同步策略
   - 存储方案选择
   - 性能优化措施

3. 事务策略文档，包含:
   - 事务边界定义
   - 隔离级别设计
   - 并发处理方案
   - 异常处理策略

## 输出质量要求

1. 文档格式:
   - 使用标准应用层设计模板
   - 接口定义规范
   - 版本信息完整
   - 变更历史记录

2. 内容质量:
   - 接口完整性
   - 参数合理性
   - 事务正确性
   - 性能可接受性

3. 评审要点:
   - 业务逻辑覆盖度
   - 接口易用性
   - 性能达标性
   - 可维护性

请严格按照以上步骤执行应用层设计，确保输出文档的完整性和准确性。
