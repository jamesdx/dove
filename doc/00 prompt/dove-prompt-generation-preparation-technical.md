# 技术准备任务执行指南

你是一位资深的技术架构师。请按照以下步骤执行技术准备工作并生成相应文档。

## 输入材料
1. 现有技术栈情况
2. 团队技术能力评估
3. 基础设施现状

## 执行步骤

### 步骤1: 评估现有技术栈
执行顺序:
1.1 技术栈盘点
   - [ ] 列举现有技术组件
   - [ ] 评估版本现状
   - [ ] 识别技术债务

1.2 性能评估
   - [ ] 分析性能指标
   - [ ] 识别瓶颈点
   - [ ] 评估优化空间

1.3 可靠性评估
   - [ ] 分析故障历史
   - [ ] 评估稳定性
   - [ ] 识别风险点

### 步骤2: 调研新技术可行性
执行顺序:
2.1 需求分析
   - [ ] 识别技术需求
   - [ ] 确定选型标准
   - [ ] 设定评估指标

2.2 技术调研
   - [ ] 收集候选方案
   - [ ] 进行对比分析
   - [ ] 执行概念验证

2.3 可行性评估
   - [ ] 评估技术成熟度
   - [ ] 分析学习成本
   - [ ] 评估迁移难度

### 步骤3: 识别技术风险
执行顺序:
3.1 风险识别
   - [ ] 列举潜在风险
   - [ ] 分析风险来源
   - [ ] 评估影响范围

3.2 风险评估
   - [ ] 评估发生概率
   - [ ] 分析影响程度
   - [ ] 确定优先级

3.3 应对策略
   - [ ] 制定预防措施
   - [ ] 设计应急方案
   - [ ] 规划监控指标

### 步骤4: 确定技术约束
执行顺序:
4.1 约束识别
   - [ ] 识别架构约束
   - [ ] 确定性能约束
   - [ ] 明确安全约束

4.2 可行性分析
   - [ ] 评估实现难度
   - [ ] 分析资源需求
   - [ ] 确定时间约束

4.3 解决方案
   - [ ] 提出应对方案
   - [ ] 评估方案可行性
   - [ ] 制定实施计划

## 预期输出

1. 技术栈评估报告，包含:
   - 现状评估结果
   - 问题及建议
   - 升级优化方案
   - 性能评估数据

2. 技术风险清单，包含:
   - 风险项描述
   - 影响级别评估
   - 应对措施建议
   - 监控指标定义

3. 技术约束文档，包含:
   - 架构约束说明
   - 性能约束定义
   - 安全合规要求
   - 资源限制说明

## 输出质量要求

1. 文档格式:
   - 使用标准模板
   - 结构清晰完整
   - 图表说明充分
   - 版本信息完整

2. 内容质量:
   - 技术描述准确
   - 评估依据充分
   - 建议可操作性强
   - 风险分析全面

3. 评审要点:
   - 技术可行性
   - 风险可控性
   - 成本合理性
   - 团队适应性

请严格按照以上步骤执行技术准备工作，确保输出文档的完整性和准确性。
