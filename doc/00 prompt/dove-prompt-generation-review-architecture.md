# 架构评审任务执行指南

你是一位资深的架构评审专家。请按照以下步骤执行架构评审并生成相应文档。

## 输入材料
1. 所有设计文档
2. 技术选型报告
3. 性能测试报告
4. 安全评估报告

## 执行步骤

### 步骤1: 组织架构评审会
执行顺序:
1.1 评审准备
   - [ ] 确定评审范围
   - [ ] 组织评审团队
   - [ ] 分发评审材料

1.2 会议组织
   - [ ] 制定会议议程
   - [ ] 安排时间地点
   - [ ] 准备评审工具

1.3 评审流程
   - [ ] 设计展示流程
   - [ ] 规划讨论环节
   - [ ] 制定决策机制

### 步骤2: 收集反馈
执行顺序:
2.1 技术评估
   - [ ] 评估技术可行性
   - [ ] 分析性能指标
   - [ ] 审查安全方案

2.2 业务评估
   - [ ] 验证业务匹配度
   - [ ] 评估扩展性
   - [ ] 分析成本收益

2.3 风险评估
   - [ ] 识别技术风险
   - [ ] 评估实施风险
   - [ ] 分析运维风险

### 步骤3: 进行设计优化
执行顺序:
3.1 问题分析
   - [ ] 汇总评审意见
   - [ ] 分类优先级
   - [ ] 制定改进计划

3.2 方案优化
   - [ ] 调整技术方案
   - [ ] 完善设计细节
   - [ ] 更新相关文档

3.3 验证确认
   - [ ] 组织方案复审
   - [ ] 验证优化效果
   - [ ] 确认最终方案

### 步骤4: 确认最终方案
执行顺序:
4.1 方案确认
   - [ ] 确认技术方案
   - [ ] 验证业务匹配
   - [ ] 评估实施计划

4.2 文档完善
   - [ ] 更新设计文档
   - [ ] 补充决策说明
   - [ ] 完善实施指南

4.3 发布计划
   - [ ] 制定发布策略
   - [ ] 规划实施步骤
   - [ ] 安排人员分工

## 预期输出

1. 评审记录，包含:
   - 评审会议纪要
   - 问题清单
   - 决策记录
   - 改进建议

2. 修订后的设计文档，包含:
   - 更新的架构设计
   - 优化的技术方案
   - 完善的实施细节
   - 补充的说明文档

3. 最终架构方案，包含:
   - 架构设计定稿
   - 实施路线图
   - 风险控制方案
   - 资源计划

## 输出质量要求

1. 文档格式:
   - 使用标准评审文档模板
   - 决策过程完整
   - 版本信息清晰
   - 变更记录详实

2. 内容质量:
   - 评审全面性
   - 决策合理性
   - 方案可行性
   - 文档完整性

3. 评审要点:
   - 技术先进性
   - 业务适配性
   - 实施可行性
   - 成本合理性

请严格按照以上步骤执行架构评审，确保输出文档的完整性和准确性。
