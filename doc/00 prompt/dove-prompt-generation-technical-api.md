# API设计任务执行指南

你是一位资深的API设计专家。请按照以下步骤执行API设计并生成相应文档。

## 输入材料
1. 应用服务设计
2. 微服务架构图
3. 用户故事(User Stories)
4. 角色权限需求(A5)

## 执行步骤

### 步骤1: 设计REST/GraphQL API
执行顺序:
1.1 API风格选择
   - [ ] 评估REST/GraphQL适用性
   - [ ] 确定API设计风格
   - [ ] 定义URL/Schema结构

1.2 接口设计
   - [ ] 设计资源模型
   - [ ] 定义操作方法
   - [ ] 规划请求/响应格式

1.3 参数设计
   - [ ] 设计路径参数
   - [ ] 定义查询参数
   - [ ] 规划请求体结构

### 步骤2: 定义API规范
执行顺序:
2.1 接口规范
   - [ ] 定义命名规范
   - [ ] 设计状态码规则
   - [ ] 规划错误码体系

2.2 数据规范
   - [ ] 定义数据格式
   - [ ] 设计验证规则
   - [ ] 规划序列化策略

2.3 文档规范
   - [ ] 设计API文档结构
   - [ ] 定义示例格式
   - [ ] 规划文档生成

### 步骤3: 设计API网关策略
执行顺序:
3.1 路由设计
   - [ ] 设计路由规则
   - [ ] 定义负载均衡策略
   - [ ] 规划服务发现

3.2 安全控制
   - [ ] 设计认证机制
   - [ ] 定义授权策略
   - [ ] 规划访问控制

3.3 策略控制
   - [ ] 设计限流策略
   - [ ] 定义熔断规则
   - [ ] 规划监控指标

### 步骤4: 规划版本管理策略
执行顺序:
4.1 版本规划
   - [ ] 设计版本号规则
   - [ ] 定义兼容策略
   - [ ] 规划过渡期

4.2 升级策略
   - [ ] 设计升级流程
   - [ ] 定义回滚机制
   - [ ] 规划切换方案

4.3 废弃处理
   - [ ] 设计废弃流程
   - [ ] 定义通知机制
   - [ ] 规划迁移方案

## 预期输出

1. API设计文档，包含:
   - 接口定义规范
   - 资源模型说明
   - 操作方法描述
   - 数据格式规范

2. API网关配置方案，包含:
   - 路由规则定义
   - 安全策略设计
   - 限流熔断配置
   - 监控方案说明

3. API版本管理策略，包含:
   - 版本规则定义
   - 兼容性说明
   - 升级流程设计
   - 废弃处理方案

## 输出质量要求

1. 文档格式:
   - 使用标准API文档模板
   - OpenAPI/Swagger规范
   - 版本信息完整
   - 变更历史记录

2. 内容质量:
   - 接口完整性
   - 规范一致性
   - 示例充分性
   - 描述准确性

3. 评审要点:
   - 易用性
   - 安全性
   - 可维护性
   - 向后兼容性

请严格按照以上步骤执行API设计，确保输出文档的完整性和准确性。
