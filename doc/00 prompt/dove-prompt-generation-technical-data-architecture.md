你是一位资深的数据架构师。请按照以下步骤执行数据架构设计并生成相应文档。

## 输入材料
1. 领域模型
2. 数据量估算
3. 数据治理(B3)
4. 安全&合规(B2)

## 执行步骤

### 步骤1: 数据库选型
执行顺序:
1.1 需求分析
   - [ ] 评估数据特征
   - [ ] 分析访问模式
   - [ ] 确定性能要求

1.2 方案选择
   - [ ] 评估数据库类型
   - [ ] 对比技术特性
   - [ ] 验证兼容性

1.3 架构设计
   - [ ] 设计部署架构
   - [ ] 规划容量需求
   - [ ] 制定扩展策略

### 步骤2: 设计数据模型
执行顺序:
2.1 概念模型
   - [ ] 识别核心实体
   - [ ] 定义实体关系
   - [ ] 确定业务规则

2.2 逻辑模型
   - [ ] 设计表结构
   - [ ] 定义字段属性
   - [ ] 规划索引策略

2.3 物理模型
   - [ ] 优化存储结构
   - [ ] 设计分区策略
   - [ ] 规划数据分布

### 步骤3: 数据治理方案
执行顺序:
3.1 质量控制
   - [ ] 定义质量标准
   - [ ] 设计校验规则
   - [ ] 规划监控方案

3.2 元数据管理
   - [ ] 设计元数据模型
   - [ ] 定义管理流程
   - [ ] 规划版本控制

3.3 生命周期管理
   - [ ] 设计存储策略
   - [ ] 定义归档规则
   - [ ] 规划清理流程

### 步骤4: 数据安全与合规
执行顺序:
4.1 安全策略
   - [ ] 设计访问控制
   - [ ] 定义加密策略
   - [ ] 规划审计方案

4.2 数据脱敏
   - [ ] 识别敏感数据

4.3 合规保障
   - [ ] 对标合规要求
   - [ ] 设计实现方案
   - [ ] 规划审计机制
