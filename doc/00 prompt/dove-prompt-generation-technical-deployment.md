# 部署架构设计任务执行指南

你是一位资深的部署架构师。请按照以下步骤执行部署架构设计并生成相应文档。

## 输入材料
1. 系统规模需求
2. 可用性需求
3. 灾备&BCP指标(B5)
4. 迭代频率/CI需求(F4)

## 执行步骤

### 步骤1: 设计容器化方案
执行顺序:
1.1 容器需求分析
   - [ ] 评估容器化范围
   - [ ] 确定隔离要求
   - [ ] 分析资源需求

1.2 镜像设计
   - [ ] 设计基础镜像
   - [ ] 定义分层策略
   - [ ] 规划构建流程

1.3 编排设计
   - [ ] 设计部署单元
   - [ ] 规划资源配额
   - [ ] 定义调度策略

### 步骤2: 规划K8s集群架构
执行顺序:
2.1 集群规划
   - [ ] 设计集群规模
   - [ ] 规划节点类型
   - [ ] 定义网络方案

2.2 高可用设计
   - [ ] 设计控制平面
   - [ ] 规划数据备份
   - [ ] 定义故障转移

2.3 运维规划
   - [ ] 设计监控方案
   - [ ] 规划日志收集
   - [ ] 定义告警策略

### 步骤3: 设计CI/CD流程
执行顺序:
3.1 流水线设计
   - [ ] 设计构建流程
   - [ ] 规划测试策略
   - [ ] 定义部署步骤

3.2 环境管理
   - [ ] 设计环境分离
   - [ ] 规划配置管理
   - [ ] 定义发布策略

3.3 自动化策略
   - [ ] 设计自动化测试
   - [ ] 规划自动部署
   - [ ] 定义回滚机制

### 步骤4: 制定灾备方案
执行顺序:
4.1 多活设计
   - [ ] 设计多活架构
   - [ ] 规划数据同步
   - [ ] 定义切换策略

4.2 故障切换
   - [ ] 设计切换机制
   - [ ] 规划恢复流程
   - [ ] 定义演练方案

4.3 业务连续性
   - [ ] 设计应急预案
   - [ ] 规划降级方案
   - [ ] 定义恢复目标

## 预期输出

1. 部署架构文档，包含:
   - 整体部署架构
   - 容器化方案
   - 集群架构设计
   - 网络拓扑图

2. CI/CD流程图，包含:
   - 流水线设计
   - 环境管理方案
   - 自动化策略
   - 发布流程说明

3. 灾备方案，包含:
   - 多活架构设计
   - 故障切换流程
   - 数据备份策略
   - 恢复演练计划

4. K8s配置模板，包含:
   - 部署配置文件
   - 服务定义模板
   - 资源配额设置
   - 网络策略定义

## 输出质量要求

1. 文档格式:
   - 使用标准架构文档模板
   - 架构图表规范
   - 版本信息完整
   - 变更历史记录

2. 内容质量:
   - 方案完整性
   - 可实现性
   - 可维护性
   - 可扩展性

3. 评审要点:
   - 高可用性
   - 可运维性
   - 安全合规性
   - 成本合理性
