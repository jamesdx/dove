# 第三方集成设计任务执行指南

你是一位资深的系统集成架构师。请按照以下步骤执行第三方集成设计并生成相应文档。

## 输入材料
1. 外部系统接口文档
2. 集成需求
3. 第三方API/SDK(D1)

## 执行步骤

### 步骤1: 设计集成方式
执行顺序:
1.1 需求分析
   - [ ] 分析集成场景
   - [ ] 确定交互模式
   - [ ] 评估性能要求

1.2 方案选择
   - [ ] 选择集成模式
   - [ ] 确定通信协议
   - [ ] 设计数据格式

1.3 架构设计
   - [ ] 设计集成架构
   - [ ] 规划部署方案
   - [ ] 制定扩展策略

### 步骤2: 规划防腐层
执行顺序:
2.1 边界分析
   - [ ] 识别集成边界
   - [ ] 确定隔离需求
   - [ ] 评估变更风险

2.2 适配设计
   - [ ] 设计数据转换
   - [ ] 定义接口适配
   - [ ] 规划版本兼容

2.3 实现策略
   - [ ] 设计实现方案
   - [ ] 定义异常处理
   - [ ] 规划测试策略

### 步骤3: 设计错误处理
执行顺序:
3.1 异常识别
   - [ ] 识别异常类型
   - [ ] 定义错误码
   - [ ] 设计重试策略

3.2 补偿机制
   - [ ] 设计补偿流程
   - [ ] 定义回滚策略
   - [ ] 规划数据一致性

3.3 监控告警
   - [ ] 设计监控指标
   - [ ] 定义告警规则
   - [ ] 规划应急预案

### 步骤4: 规划熔断限流
执行顺序:
4.1 策略设计
   - [ ] 设计熔断策略
   - [ ] 定义限流规则
   - [ ] 规划降级方案

4.2 阈值管理
   - [ ] 设计阈值指标
   - [ ] 定义动态调整
   - [ ] 规划预警机制

4.3 恢复机制
   - [ ] 设计恢复策略
   - [ ] 定义切换规则
   - [ ] 规划灰度方案

1. 集成架构方案，包含:

3. 异常处理策略，包含:
   - 异常处理流程

   - 熔断策略定义
   - 限流规则设计

   - 恢复机制设计
