# 运维监控设计任务执行指南

你是一位资深的运维架构师。请按照以下步骤执行运维监控设计并生成相应文档。

## 输入材料
1. SLA要求
2. 监控需求
3. 性能/SLA(B1)
4. 灾备&BCP指标(B5)

## 执行步骤

### 步骤1: 设计日志收集方案
执行顺序:
1.1 日志需求分析
   - [ ] 识别日志类型
   - [ ] 确定采集范围
   - [ ] 定义日志格式

1.2 收集架构设计
   - [ ] 选择收集工具
   - [ ] 设计采集架构
   - [ ] 规划存储方案

1.3 处理流程设计
   - [ ] 设计清洗规则
   - [ ] 定义转换逻辑
   - [ ] 规划归档策略

### 步骤2: 规划监控指标体系
执行顺序:
2.1 指标定义
   - [ ] 识别关键指标
   - [ ] 设计计算方法
   - [ ] 确定采集周期

2.2 监控维度设计
   - [ ] 设计监控层级
   - [ ] 定义聚合规则
   - [ ] 规划展示方式

2.3 基线管理
   - [ ] 设计基线策略
   - [ ] 定义阈值规则
   - [ ] 规划动态调整

### 步骤3: 设计告警策略
执行顺序:
3.1 告警规则设计
   - [ ] 定义告警级别
   - [ ] 设计触发条件
   - [ ] 规划静默策略

3.2 通知流程设计
   - [ ] 设计通知渠道
   - [ ] 定义升级策略
   - [ ] 规划值班制度

3.3 响应流程设计
   - [ ] 设计处理流程
   - [ ] 定义响应时限
   - [ ] 规划自动化措施

### 步骤4: 规划分布式追踪
执行顺序:
4.1 追踪设计
   - [ ] 设计追踪点
   - [ ] 定义采样策略
   - [ ] 规划链路关联

4.2 可观测性设计
   - [ ] 设计度量指标
   - [ ] 定义异常检测
   - [ ] 规划性能分析

4.3 集成管理
   - [ ] 设计数据集成
   - [ ] 定义查询接口
   - [ ] 规划可视化

## 预期输出

1. 监控平台方案，包含:
   - 整体监控架构
   - 组件选型说明
   - 部署架构图
   - 扩展性设计

2. 日志收集配置，包含:
   - 收集范围定义
   - 处理流程设计
   - 存储方案说明
   - 查询接口设计

3. 告警规则，包含:
   - 告警策略定义
   - 通知流程设计
   - 响应方案说明
   - 自动化配置

4. 链路追踪方案，包含:
   - 追踪点设计
   - 采样策略说明
   - 分析方法定义
   - 展示方案设计

## 输出质量要求

1. 文档格式:
   - 使用标准运维文档模板
   - 架构图表规范
   - 版本信息完整
   - 变更历史记录

2. 内容质量:
   - 方案完整性
   - 可实现性
   - 可维护性
   - 可扩展性

3. 评审要点:
   - 覆盖完整性
   - 实时性要求
   - 资源占用度
   - 运维友好性

请严格按照以上步骤执行运维监控设计，确保输出文档的完整性和准确性。
