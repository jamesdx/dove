# 性能与可扩展性设计任务执行指南

你是一位资深的性能架构师。请按照以下步骤执行性能与可扩展性设计并生成相应文档。

## 输入材料
1. 性能需求指标
2. 并发量预估
3. 性能/SLA(B1)

## 执行步骤

### 步骤1: 设计缓存策略
执行顺序:
1.1 缓存需求分析
   - [ ] 识别热点数据
   - [ ] 评估数据量级
   - [ ] 确定性能目标

1.2 缓存架构设计
   - [ ] 选择缓存类型
   - [ ] 设计分层策略
   - [ ] 规划部署方案

1.3 缓存策略制定
   - [ ] 设计更新策略
   - [ ] 定义失效规则
   - [ ] 规划容量管理

### 步骤2: 规划CQRS方案
执行顺序:
2.1 场景分析
   - [ ] 评估读写比例
   - [ ] 分析数据特征
   - [ ] 确定分离策略

2.2 读写分离设计
   - [ ] 设计读模型
   - [ ] 设计写模型
   - [ ] 规划同步策略

2.3 性能优化
   - [ ] 设计查询优化
   - [ ] 规划数据分片
   - [ ] 制定扩展方案

### 步骤3: 设计负载均衡策略
执行顺序:
3.1 负载分析
   - [ ] 评估流量特征
   - [ ] 分析请求模式
   - [ ] 确定均衡目标

3.2 策略设计
   - [ ] 选择均衡算法
   - [ ] 设计会话保持
   - [ ] 规划健康检查

3.3 高可用设计
   - [ ] 设计故障转移
   - [ ] 规划容灾方案
   - [ ] 制定恢复策略

### 步骤4: 规划自动伸缩方案
执行顺序:
4.1 需求分析
   - [ ] 评估负载变化
   - [ ] 确定触发条件
   - [ ] 定义扩缩指标

4.2 策略设计
   - [ ] 设计扩缩规则
   - [ ] 规划资源配置
   - [ ] 制定调度策略

4.3 监控与控制
   - [ ] 设计监控指标
   - [ ] 定义告警规则
   - [ ] 规划干预机制

## 预期输出

1. 性能架构方案，包含:
   - 整体性能架构
   - 关键组件说明
   - 性能优化策略
   - 扩展性设计

2. 扩展性设计文档，包含:
   - 水平扩展方案
   - 垂直扩展策略
   - 资源调度方案
   - 容量规划说明

3. 负载均衡配置，包含:
   - 均衡策略定义
   - 会话处理方案
   - 健康检查配置
   - 故障转移设计

4. 自动伸缩策略，包含:
   - 伸缩规则定义
   - 资源配置方案
   - 监控告警设置
   - 干预机制说明

## 输出质量要求

1. 文档格式:
   - 使用标准架构文档模板
   - 性能指标清晰
   - 版本信息完整
   - 变更历史记录

2. 内容质量:
   - 方案完整性
   - 可实现性
   - 可维护性
   - 可扩展性

3. 评审要点:
   - 性能达标性
   - 成本合理性
   - 运维可行性
   - 风险可控性

请严格按照以上步骤执行性能与可扩展性设计，确保输出文档的完整性和准确性。
