# 安全架构设计任务执行指南

你是一位资深的安全架构师。请按照以下步骤执行安全架构设计并生成相应文档。

## 输入材料
1. 安全需求
2. 合规要求
3. 角色权限需求(A5)
4. 安全&合规(B2)

## 执行步骤

### 步骤1: 设计认证授权方案
执行顺序:
1.1 认证设计
   - [ ] 设计认证机制
   - [ ] 定义身份源
   - [ ] 规划认证流程

1.2 授权设计
   - [ ] 设计权限模型
   - [ ] 定义角色体系
   - [ ] 规划访问控制

1.3 会话管理
   - [ ] 设计会话机制
   - [ ] 定义超时策略
   - [ ] 规划状态管理

### 步骤2: 规划数据加密策略
执行顺序:
2.1 加密需求
   - [ ] 识别加密对象
   - [ ] 确定加密级别
   - [ ] 选择加密算法

2.2 密钥管理
   - [ ] 设计密钥体系
   - [ ] 定义生命周期
   - [ ] 规划密钥分发

2.3 传输安全
   - [ ] 设计传输加密
   - [ ] 定义协议版本
   - [ ] 规划证书管理

### 步骤3: 制定安全审计方案
执行顺序:
3.1 审计范围
   - [ ] 确定审计对象
   - [ ] 定义审计事件
   - [ ] 设计采集策略

3.2 审计实现
   - [ ] 设计审计日志
   - [ ] 规划存储方案
   - [ ] 定义查询接口

3.3 监控告警
   - [ ] 设计监控指标
   - [ ] 定义告警规则
   - [ ] 规划响应流程

### 步骤4: 设计零信任架构
执行顺序:
4.1 访问控制
   - [ ] 设计动态授权
   - [ ] 定义信任评估
   - [ ] 规划访问策略

4.2 网络隔离
   - [ ] 设计网络分区
   - [ ] 定义访问规则
   - [ ] 规划流量控制

4.3 持续验证
   - [ ] 设计验证机制
   - [ ] 定义评估指标
   - [ ] 规划响应策略

## 预期输出

1. 安全架构设计文档，包含:
   - 整体安全架构
   - 安全组件说明
   - 部署架构图
   - 安全流程设计

2. 加密方案，包含:
   - 加密策略定义
   - 密钥管理方案
   - 传输安全设计
   - 存储加密方案

3. 审计方案，包含:
   - 审计范围定义
   - 日志规范设计
   - 存储方案说明
   - 查询接口设计

4. 安全合规评估报告，包含:
   - 合规要求对照
   - 实现方案说明
   - 风险评估结果
   - 改进建议清单

## 输出质量要求

1. 文档格式:
   - 使用标准安全文档模板
   - 架构图表规范
   - 版本信息完整
   - 变更历史记录

2. 内容质量:
   - 方案完整性
   - 实现可行性
   - 合规达标性
   - 说明充分性

3. 评审要点:
   - 安全有效性
   - 性能影响度
   - 运维可行性
   - 用户体验性

请严格按照以上步骤执行安全架构设计，确保输出文档的完整性和准确性。
